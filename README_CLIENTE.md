# Alerta de Assuntos - Cliente

Versão cliente 1.0 baseada no motor validado da V0.7.

## Diferenças da edição cliente
- Aplicativo separado: `com.monitorwhatsapp.client`
- Interface simplificada, sem painel técnico na tela principal
- Regras por conversa/grupo, remetente e palavras-chave
- Remetente sem palavras: qualquer mensagem da pessoa gera alerta
- Remetente + palavras: ambos precisam corresponder
- Ao informar uma conversa/grupo, as notificações normais daquela conversa são ocultadas e só os alertas configurados chamam atenção
- Histórico de alertas e abertura do WhatsApp
- Diagnóstico disponível apenas em Ajuda e suporte
- Sem permissão de Internet

## Observação
O Android exige que o próprio usuário conceda manualmente o Acesso às notificações.
